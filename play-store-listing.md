## Full description

AI Super Cleaner Ultimate is a local-first Android utility that helps you understand, organize, and manage device storage with clear user controls. Scans and file-management operations run on the device; the app does not upload your personal files, vault contents, scan results, or file list to the developer.

**Clean and organize storage**

• Scan temporary files, cache residue, logs, thumbnails, and other cleanup candidates.
• Find duplicate and similar files so you can review what is safe to remove.
• Identify large files and review storage usage before cleaning.
• Review cleanup history, reclaimed space, and items moved to Trash where supported.
• Permanently erase selected files with the secure file shredder.

**Privacy and security tools**

• Scan user-launchable applications and their declared permissions with Privacy Scanner.
• Review privacy risks and open Android settings for an application when you choose.
• Keep selected private files in a local encrypted, biometric-protected vault.
• Check available Wi-Fi security information using Android’s supported network APIs.

**Performance and automation**

• View device RAM and battery information.
• Configure cleanup rules for recurring local cleanup preferences.
• Schedule optional automatic cleanup and storage-alert notifications.
• Review local cleanup history and adjust app theme and language settings.

**Free and Premium options**

The free experience is supported by Google AdMob advertisements. Premium options remove advertisements and unlock the Premium features available in the app. Google Play Billing manages the monthly subscription and one-time lifetime purchase.

The app requests Android permissions needed for its functions, including file and media access. Privacy Scanner uses narrowly scoped package visibility for user-launchable applications and does not request `QUERY_ALL_PACKAGES`. Full-file cleaning requires broad file-management access on supported Android versions. Review each permission explanation in the app before granting access.

Advertising, consent, and billing providers may process information under their own policies and your consent choices. Read the Privacy Policy before using the app.
