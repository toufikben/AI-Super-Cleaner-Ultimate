# AI Super Cleaner Ultimate

تطبيق Android حقيقي لفهم التخزين وتنظيفه بأمان، مع أولوية للخصوصية والدقة قبل تحقيق الدخل.

## حالة المشروع

**المرحلة 1 مكتملة:** تأسيس مشروع Android، هوية Material 3، UI/UX، الملاحة، وثيم قابل للتوسع.

**المرحلة 2 مكتملة:** إدارة الصلاحيات السياقية، Privacy Center، وتفضيلات محلية غير حساسة دون `MANAGE_EXTERNAL_STORAGE`.

**المرحلة 3 مكتملة:** ماسح MediaStore حقيقي للصور والفيديو والصوت، قاعدة Room محلية، تقدم تدريجي قابل للإلغاء، ولوحة Home مرتبطة ببيانات الجهاز الفعلية.

**المرحلة 4 مكتملة:** Smart Cleanup Score ومحرك توصيات قابل للتفسير يعرض السبب والثقة والحجم وعدد الملفات.

> لا يصف التطبيق الملفات بأنها Junk. الحجم الكبير أو اسم Screenshot يقدمان سبباً للمراجعة فقط، والقرار دائماً للمستخدم.

## Explainable AI

تُحسب الدرجة من ضغط التخزين الفعلي وحجم الفئات عالية الثقة القابلة للمراجعة. التوصيات الحالية تشمل الفيديوهات الكبيرة ابتداءً من 500 MB، الصور الكبيرة ابتداءً من 20 MB، ولقطات الشاشة التي يدل عليها الاسم المتاح. كل توصية تعرض سبباً وثقة وحجماً وعدد ملفات. Exact Duplicates وPerceptual Similarity وML البصري تنفذ في المراحل التالية.

## البنية المحلية والخصوصية

يستخدم التطبيق `StorageScanner` مع `ContentResolver` وMediaStore، ويعمل المسح على `Dispatchers.IO` على دفعات صغيرة مع cancellation. تحفظ Room metadata فقط مثل URI، الاسم المتاح، MIME type، الحجم، تاريخ التعديل، ونوع الوسيط، إضافة إلى سجل المسح. لا تُحفظ محتويات الصور أو الفيديو أو الصوت ولا تُرفع إلى خادم.

## البناء

يتطلب البناء المحلي Android SDK 35 وJDK 17 أو أحدث. شغّل:

```bash
./gradlew assembleDebug lintDebug
```

## خارطة التنفيذ التالية

1. محركات التكرار والتشابه وتحليل الصور.
2. التنظيف الآمن وTrash والاستعادة.
3. الفيديو والملفات الكبيرة والتنزيلات والصوت.
4. ضغط الصور والفيديو.
5. Advanced Scan ثم الأداء.
6. AdMob ثم Billing وPremium بعد إثبات قيمة المنظف الأساسي.
