# AI Super Cleaner Ultimate

تطبيق Android حقيقي لفهم التخزين وتنظيفه بأمان، مع أولوية للخصوصية والدقة قبل تحقيق الدخل.

## حالة المشروع

**المرحلة 1 مكتملة:** تأسيس مشروع Android، هوية Material 3، UI/UX، الملاحة، وثيم قابل للتوسع.

**المرحلة 2 مكتملة:** إدارة الصلاحيات السياقية، Privacy Center، وتفضيلات محلية غير حساسة دون `MANAGE_EXTERNAL_STORAGE`.

> الماسح الحقيقي وقاعدة البيانات التفصيلية ينفذان في المرحلة 3. أي أرقام ظاهرة حالياً في واجهة التصميم مؤقتة ولا تمثل إحصاءات فعلية للجهاز.

## سياسة الوصول والخصوصية

يطلب التطبيق أقل صلاحيات لازمة عند بدء Smart Scan فقط. يستخدم `MediaStore` مع `READ_MEDIA_IMAGES` و`READ_MEDIA_VIDEO` و`READ_MEDIA_AUDIO` على Android 13+، ويستخدم `READ_EXTERNAL_STORAGE` بحد أقصى API 32 على الإصدارات الأقدم. لا يستخدم `MANAGE_EXTERNAL_STORAGE`، ولا يتجاوز قيود Android للوصول إلى ملفات غير متاحة.

تبقى عمليات المسح والتحليل الأساسية محلية. لا تُرفع الصور أو الملفات في التنظيف العادي. يحتوي Settings على Privacy Center يشرح ما يتم الوصول إليه وما يبقى على الجهاز وما لا يُطلب. التحليلات الاختيارية مغلقة افتراضياً ولا تشمل أسماء الملفات أو محتوى الوسائط.

## تصميم UI/UX

تتبع الواجهة مبادئ المنتج الأساسية. يعرض Home الحالة العامة للتخزين وSmart Scan كإجراء رئيسي، ويضع Smart Cleanup Score التفسير والثقة في قلب التجربة. يظهر شرح الخصوصية قبل طلب الوصول، ولا يبدأ المسح عند رفض الصلاحية. تتوفر الملاحة Home وClean وAnalyze وTools وSettings، مع Material 3 وتصميم Light/Dark-ready ودعم RTL.

## البناء

يتطلب البناء المحلي Android SDK 35 وJDK 17 أو أحدث. شغّل:

```bash
./gradlew assembleDebug lintDebug
```
