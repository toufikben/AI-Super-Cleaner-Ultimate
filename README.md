# AI Super Cleaner Ultimate

تطبيق Android حقيقي لفهم التخزين وتنظيفه بأمان، مع أولوية للخصوصية والدقة قبل تحقيق الدخل.

## حالة المشروع

**المرحلة 1 مكتملة:** تأسيس مشروع Android، هوية Material 3، UI/UX، الملاحة، وثيم قابل للتوسع.

**المرحلة 2 مكتملة:** إدارة الصلاحيات السياقية، Privacy Center، وتفضيلات محلية غير حساسة دون `MANAGE_EXTERNAL_STORAGE`.

**المرحلة 3 مكتملة:** ماسح MediaStore حقيقي للصور والفيديو والصوت، قاعدة Room محلية، تقدم تدريجي قابل للإلغاء، ولوحة Home مرتبطة ببيانات الجهاز الفعلية.

**المرحلة 4 مكتملة:** Smart Cleanup Score ومحرك توصيات قابل للتفسير.

**المرحلة 5 مكتملة:** Exact Duplicate Engine وPerceptual Similarity ومؤشر الضبابية واكتشاف أولي للقطات الشاشة.

**المرحلة 6 مكتملة:** مراجعة يدوية، MediaStore Trash قابلة للاستعادة، Restore، وPermanent Delete بتأكيد منفصل.

## التنظيف الآمن

يعرض Clean الملفات المرشحة التي تحتوي على content hash، ولا يحدد أي ملف تلقائياً. بعد اختيار المستخدم يعرض العدد والحجم قبل النقل إلى Trash. يستخدم التطبيق `IS_TRASHED` و`DATE_EXPIRES` حيث يدعم Android ذلك، ويسجل metadata السلة في Room. يمكن استعادة العناصر من Tools > Trash أو حذفها نهائياً بعد تأكيد مستقل.

على Android الأقدم من API 29 لا ينفذ التطبيق حذفاً غير قابل للتراجع عبر هذا المسار. كما لا ينسخ الملفات الضخمة إلى نسخة ثانية بلا ضرورة.

## الخصوصية

تظل الملفات على الجهاز. لا يستخدم التطبيق `MANAGE_EXTERNAL_STORAGE` ولا يتجاوز قيود Android. تحفظ Room metadata والبصمات ونتائج التحليل دون رفع محتوى الوسائط.

## البناء

```bash
./gradlew assembleDebug lintDebug
```
