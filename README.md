# AI Super Cleaner Ultimate

تطبيق Android حقيقي لفهم التخزين وتنظيفه بأمان، مع أولوية للخصوصية والدقة قبل تحقيق الدخل.

## حالة المشروع

**المرحلة 1 مكتملة محلياً:** تأسيس مشروع Android، هوية Material 3، UI/UX أولي، الملاحة السفلية، دعم RTL عبر `supportsRtl`، وثيم قابل للتوسع.

> هذه المرحلة لا تدّعي وجود ماسح حقيقي بعد. البيانات المعروضة في واجهة المرحلة الأولى هي بيانات تصميمية مؤقتة إلى أن تكتمل المرحلة 3، ولن تُستخدم كإحصاءات فعلية في الإصدار الوظيفي.

## تصميم UI/UX

تتبع الواجهة مبادئ المنتج الأساسية:

- Home يعرض الحالة العامة للتخزين وSmart Scan كإجراء رئيسي.
- Smart Cleanup Score يضع الثقة والتفسير في قلب الشاشة.
- Quick Clean وAnalyze إجراءان ثانويان واضحان.
- بطاقات التوصيات تذكر الفئة والسبب والحجم دون استخدام كلمة Junk بلا تبرير.
- Privacy note ظاهرة في الصفحة الرئيسية لتأكيد Local-first.
- Material 3، Light/Dark-ready، وألوان هادئة بعيدة عن أسلوب RAM Booster.
- Bottom navigation: Home، Clean، Analyze، Tools، Settings.

## البناء

يتطلب البناء المحلي Android SDK 35 وJDK 17 أو أحدث. شغّل:

```bash
./gradlew assembleDebug
```

إذا لم يوجد Android SDK في بيئة التطوير، افتح المشروع في Android Studio وثبّت Android SDK Platform 35 وBuild Tools المناسبة.
