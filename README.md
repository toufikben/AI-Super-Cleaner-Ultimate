# AI Super Cleaner Ultimate

تطبيق Android حقيقي لفهم التخزين وتنظيفه بأمان، مع أولوية للخصوصية والدقة قبل تحقيق الدخل.

## حالة المشروع

**المرحلة 1 مكتملة:** تأسيس مشروع Android، هوية Material 3، UI/UX، الملاحة، وثيم قابل للتوسع.

**المرحلة 2 مكتملة:** إدارة الصلاحيات السياقية، Privacy Center، وتفضيلات محلية غير حساسة دون `MANAGE_EXTERNAL_STORAGE`.

**المرحلة 3 مكتملة:** ماسح MediaStore حقيقي للصور والفيديو والصوت، قاعدة Room محلية، تقدم تدريجي قابل للإلغاء، ولوحة Home مرتبطة ببيانات الجهاز الفعلية.

**المرحلة 4 مكتملة:** Smart Cleanup Score ومحرك توصيات قابل للتفسير يعرض السبب والثقة والحجم وعدد الملفات.

**المرحلة 5 مكتملة:** Exact Duplicate Engine باستخدام SHA-256، وPerceptual Similarity، ومؤشر ضبابية محلي، واكتشاف أولي للقطات الشاشة.

## محركات الوسائط

تبدأ المطابقة بتصفية metadata حسب نوع الوسيط والحجم، ثم تحسب SHA-256 للمرشحين ذوي الحجم المتساوي. تحلل الصور محلياً عبر نسخة مصغرة لحساب perceptual hash ومؤشر ضبابية deterministic. تعرض Home مجموعات التكرار والتشابه والنتائج المحتمل ضبابيتها ولقطات الشاشة للمراجعة فقط. لا يوجد حذف أو تحديد تلقائي.

## الخصوصية

تظل الملفات على الجهاز. لا يستخدم التطبيق `MANAGE_EXTERNAL_STORAGE` ولا يتجاوز قيود Android. تحفظ Room metadata والبصمات ونتائج التحليل دون رفع محتوى الوسائط.

## البناء

يتطلب البناء المحلي Android SDK 35 وJDK 17 أو أحدث:

```bash
./gradlew assembleDebug lintDebug
```

## خارطة التنفيذ التالية

1. التنظيف الآمن وTrash والاستعادة.
2. محللات الفيديو والملفات الكبيرة والتنزيلات والصوت.
3. ضغط الصور والفيديو.
4. Advanced Scan ثم الأداء والـcache المتقدم.
5. AdMob ثم Billing وPremium بعد إثبات قيمة المنظف الأساسي.
